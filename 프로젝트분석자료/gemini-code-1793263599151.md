# [프론트엔드 PRD] 개발 아키텍처 및 기능 명세서

## 1. 기술 스택 (Tech Stack)
* **프레임워크**: Next.js 14+ (App Router, React Server Components)
* **스타일링**: Tailwind CSS (커스텀 테마 토큰 정의)
* **애니메이션**: Framer Motion (스크롤 트리거, 슬라이드 드로어, 탭 전환)
* **상태 관리**: Zustand (장바구니 UI 및 사용자 설정 상태)
* **타입 시스템**: TypeScript (엄격한 타입 체크)

## 2. 디자인 토큰 정의 (Design Tokens)
* **컬러 (Color Palette)**:
  * Background Main: `#000000` (Pitch Black)
  * Background Sub: `#F4F4F4` (Off White)
  * Accent Red: `#D71920` (Nothing Red)
  * Text Primary: `#FFFFFF` / `#000000`
  * Text Muted: `#888888`
* **폰트 (Typography)**:
  * Primary: NDS (Dot Matrix 커스텀 폰트)
  * Secondary: Sans-Serif (Pretendard / Inter)

## 3. 핵심 화면별 프론트엔드 요구사항
1. **헤더 & GNB 컴포넌트 (`Header.tsx`)**
   * 스크롤 내릴 때 숨김, 올려서 상단 도달 시 노출되는 스티키 애니메이션
   * 모바일 화면 시 풀스크린 풀다운 메뉴 구현
2. **히어로 컴포넌트 (`HeroSection.tsx`)**
   * 반응형 대형 텍스트 오버레이 및 배경 그래픽 최적화 (WebP / AVIF)
   * CTA(Call to Action) 버튼 호버 시 반전 효과
3. **인터랙티브 스펙 카드 (`SpecGrid.tsx`)**
   * CSS Grid 기반의 비대칭 카드 배치
   * 호버 시 내부 회로/스펙 이미지가 미세하게 확대되는 카드 애니메이션
4. **미니 장바구니 드로어 (`CartDrawer.tsx`)**
   * Zustand 연동을 통한 실시간 담기 및 수량 조절
   * 우측 슬라이드인(Slide-in) 오버레이 레이아웃
